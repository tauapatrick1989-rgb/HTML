## Como os próximos projetos serão estruturados

Cada projeto novo deve responder rapidamente:

1. **Qual problema está sendo analisado?**
2. **Qual base de dados foi utilizada?**
3. **Como os dados foram tratados?**
4. **Quais indicadores ou perguntas orientaram a análise?**
5. **Quais ferramentas foram utilizadas?**
6. **Quais conclusões podem ser tiradas dos dados?**
7. **Como executar ou visualizar o projeto?**
